# 0.3.6 交付验收

日期：2026-09-09。0.3.6 收录 `1791a4f`（浏览器工具）及 `a5d0f15`（Vue 3 迁移），并同步版本元数据、验收脚本与文档。以下区分升版后的自动化检查和升版前同一实现的浏览器实测；不覆盖 2026-09-07 的 0.3.5 Firefox 补丁记录。

## 变更与自动化检查

Vue 3 SFC 接管面板模板、表单、五模式结果、高亮与维护视图；保留 SearchPanel 业务回调、开放 Shadow DOM、编辑器接线和按模式准备。索引、同步协议、数据格式没有变化。Vue 运行时随脚本打包，模板在构建时编译。

开发工具新增可配置的原生浏览器启动与 CDP 接入、两标签生命周期预检和退出即清理的安装服务。安装导航被扩展中断后仍查找本次确认页，并要求准确版本/build marker 与 ready；CLI 打印错误但返回零时也会判定失败。

- 升至 0.3.6 后，本地全量 40 文件 / 392 项测试、SFC/TS 类型检查、生产构建通过；userscript 与 meta 的版本均核对为 0.3.6。
- 对比同一 build marker（development）的升版前后产物：user.js 和 meta.js 均只有 `@version` 从 0.3.5 变为 0.3.6，其余字节一致。
- 浏览器 JavaScript/shell 语法、文档链接及差异检查通过。
- 40 个测试入口均受 Git 跟踪，Vitest 仅收集 `tests/**/*.test.ts`；浏览器操作工具仍在 `scripts/`。
- `a5d0f15` 的 [GitHub Actions](https://github.com/Werewolf-Wu/cu-wiki-search-companion/actions/runs/34353259257) 验证/构建与滚动 Nightly 更新成功。此结论只对应该次运行，不代表之后的构建或其他部署。

没有保存 Wiki 编辑或完整重置真实镜像；临时编辑通过原生撤销恢复，只清理本次创建的页面、浏览器与服务。360 像素宽是桌面窄视口证据，手机继续按 Best-Effort 支持，根据实际使用问题修复。

## 已测开销与限制

以下为升版前迁移实验的数据。在同一原生 Chrome 中交错比较迁移前后 UI，各 3 组、每组 5 个新文档标签；每组核对同一窗口并在结束时关闭。测量只包含脚本求值与关闭状态的 UI 挂载，不包含 Wiki 网络、GM、索引恢复或同步。

| 指标 | 迁移前 | 迁移后 |
| --- | ---: | ---: |
| 整包原始字节 | 1,636,698 | 1,784,977 |
| 整包 gzip level 9 字节 | 602,671 | 637,323 |
| UI 求值与挂载中位数 | 12.0 ms | 21.6 ms |
| 单标签 GC 后 JS 堆增量中位数 | 186,604 B | 555,472 B |
| 五标签 JS 堆增量总和中位数 | 933,020 B | 2,777,360 B |

JS 堆采用 CDP JSHeapUsedSize，不能解释为进程 RSS 或完整脚本内存。迁移换取声明式视图的维护便利，代价约为 gzip 增加 34 KiB、隔离 UI 初始化增加 9.6 ms、单标签 JS 堆增加 360 KiB；不宣称性能提高，也不外推至长期多标签压力。
