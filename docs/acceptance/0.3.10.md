# 0.3.10 UI 调整验收

日期：2026-10-06。

## 变更范围

- 调整入口、面板、结果行及状态区域的字体层级、边框、圆角和间距，继续继承站点主题色。
- 收起后的入口避让站点右下角工具栏，工具栏缺失时回退到右下角；支持晚挂载、尺寸和显隐变化、移除与替换。
- 打开后隐藏入口，面板即时显示、默认底距 12px。展开面板不随工具栏移动，允许覆盖部分站点工具栏；保留自由拖动及关闭重开时的位置。
- 关闭前同步恢复入口可见状态，再归还焦点；从编辑器以快捷键打开后，关闭仍回到编辑器并保留选区。

搜索排序、六类搜索域、同步和存储协议、复制／打开／插入语义均未修改。没有新依赖。

## 本地检查

- 全套 45 个测试文件、514 项测试通过，包含入口定位生命周期与关闭焦点时序回归。
- 类型检查与生产构建通过；脚本语法及差异空白检查通过。
- 独立代码约定和需求一致性审查未发现阻断问题。

## 浏览器检查

在有界面 Chrome 的独立真实 Wiki 编辑标签页中加载当前源码的独立 UI 组件构建，使用固定结果及记录回调：

- 1200×800、800×420、360×760、3840×2160 视口下，长结果、长状态及详情、维护区域和 CSS／重定向结果布局可用。
- 实际鼠标拖动、取消拖动、方向键移动、重置位置与关闭重开通过。
- 六模式结果主动作、Enter、打开及可插入条件对应的回调序列正确；入口隐藏／恢复、实际焦点返回、连续快捷键切换通过。
- 已拖动面板不随工具栏宽度变化；入口保持 12px 间距。375px 窄屏面板底距 12px，回到桌面尺寸后恢复拖动位置。
- 实际 CodeMirror 内选中文字后，Alt+K 打开，再以 Esc 或 Alt+K 关闭，编辑器焦点与选区保持，正文未变。

浏览器检查执行于版本号调整前的同一 UI 实现；升版后复验本地测试、类型和构建，不把旧安装版本重标为新整包实测。

## 验证边界

固定样例与记录回调只证明组件交互和布局，不能代替新整包的真实搜索、剪贴板、链接打开、插入与撤销验收。本轮未安装新整包，也未保存 Wiki 编辑或重置真实镜像。

移动端仍为 Best-Effort；窄视口验证不代表全部触屏、软键盘或输入法设备。工具栏识别依赖当前皮肤 `.skin-dock`；不监听全页面属性变化，若未来皮肤改为只修改现有节点的类名来创建工具栏，需要另行适配。

自动构建与 Nightly 发布结果以对应提交的远端工作流为准，不由本地检查推断。
