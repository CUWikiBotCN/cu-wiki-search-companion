# 0.3.8 交付验收

日期：2026-10-02。本版集中修复同步与快照状态问题，并拆分搜索运行态和浮窗模块。版本、安装元数据、README、架构和验收脚本已同步；本轮仅本地提交，不推送或创建远端发布。

## 变更

- RC 事实提交后，本地索引刷新失败仍尝试广播，保留 Data 失效并继续锁后刷新，同时报告原错误。
- 标题、RC 与对账共用页面事实比较；仅 namespaceName 变化也推进 localSeq，让其他索引和标签能够重放。
- 普通运行态状态更新只读取轻量快照观察，不读其他模式的快照、不哈希或解析 payload。实际恢复和显式诊断保留完整性检查；清理/发布与在途观察互不覆盖，诊断先完成也不会阻止恢复状态登记。
- 文件与 Data 索引、规则和同步会话移入独立 runtime；保留文件按需加载、Data FIFO、写锁和规则草稿保护。main.ts 从 1075 行降至 917 行。
- 浮窗几何、拖动和布局/滚动任务独立管理；六模式展示与结果动作资格集中维护。SearchPanel 从 841 行降至 636 行，销毁取消全部任务和监听器。
- 真实构建及真实入口集成用例局部采用 15 秒超时，默认测试并行度和业务单测时限不变。布局验收等待输入防抖完成后再检查焦点。

未增加依赖或改变存储 schema、版本契约、同步协议与编辑器插入语法。
