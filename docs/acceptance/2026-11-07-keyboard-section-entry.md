# 键盘导览与小节入口验收

日期：2026-11-07。基线：`85ec18e`（0.4.1）。本记录对应 0.4.2 的本地实现与验证；提交与推送状态以 Git 记录为准，未进行新版本安装验收。

## 行为

- 移除“包含小节”复选框及手动范围状态。标题模式只有输入半角 `#` 才搜索小节；`#你知` 搜小节，`地形#你知` 同时筛页面和小节，删除分隔符恢复页面标题搜索。
- 普通页面结果右侧依次为“打开”“复制插入内容”“插入”，移除“查看小节”按钮。标题模式在搜索框或结果区按 `Ctrl+Alt+S`，将选中页面写成规范标题加 `#` 并绑定页面 ID，随后可继续输入小节名。
- `Alt+K` 唤起后搜索框获得焦点；上下键切换结果，输入焦点保持不变。结果区上下键换行并尽量保留同类操作焦点，左右键切换当前行按钮。
- 面板通过 window 捕获监听路由内部按键，先于宿主 document 捕获监听处理导航。面板外按键、搜索框左右光标移动、下拉框方向键、修饰方向键及中文组词保留原有行为。按钮 Enter 激活与关闭后的编辑器回焦继续有效。

- lint、格式、完整类型检查及生产构建通过。版本升级至 0.4.2 后重跑安装元数据测试 9 项、格式、类型与构建，均通过；产品逻辑未再修改。
- Chrome 156、Firefox 155 各 25 项真实键盘检查通过：Alt+K、搜索框和结果区导航、操作列保留、按钮激活、Tab 顺序、小节快捷键绑定、删除 `#`、Esc 回焦、窄视口及未捕获错误检查。
- 浏览器夹具在挂载面板前注册会阻止方向键及 Tab 的 document 捕获监听，确认面板导航不被抢占，面板外方向键仍到达页面。单元测试另外覆盖空结果、修饰键、组词与原生下拉框方向键。
