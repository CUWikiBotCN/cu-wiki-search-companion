# 标题模式小节搜索验收

日期：2026-11-07。基线：`19ae80e`。本记录对应 0.4.0 的本地实现与验证，未进行新版本用户脚本安装验收；提交与推送状态以 Git 记录为准。

## 已实现

- 标题模式默认关闭“包含小节”，支持面板内 `Ctrl+Alt+S`。手动范围与 `#` 的临时范围分离，删除分隔符恢复手动选择。
- `地形 #你知` 同时筛选页面与小节；先匹配全部候选，再限制条数。“查看小节”可明确限定单页；同名小节显示出现次序。
- 小节结构按需从修订匹配的本地源码派生，独立于标题与正文倒排索引。明确单页意图可自动补齐；片段查询不会自动批量下载。
- 简单结构可离线生成链接；复杂结构按单页解析接口核对。复制纯目标、复制维基链接、打开与插入使用明确的小节目标。核对完成不会自动执行操作。
- 修订与本地变更序号共同约束结果及核对缓存；过期结果会提示重新检索或核对。获取失败、取消、并发会话与迟到响应均有回归覆盖。

## 检查结果

- `npm run lint`、`npm run format:check`、`npm run build` 通过；构建包含完整类型检查。
- `npm test -- --maxWorkers=2 --testTimeout=15000`：版本升级后重跑，54 个测试文件、672 项全部通过。默认 5 秒上限下，原有一万条任务夹具超时；本轮运行保留全部断言，调整等待上限，未修改项目默认超时。
- 完整回归包含页内超过 20 个小节时，仍能检索末尾目标的用例。
- 真实 `main.ts` 入口集成测试覆盖页面/小节动作、解析接口核对、CSS 已加载时单页获取，以及写锁等待期间取消失效意图。数据库、网络与脚本管理器接口使用隔离夹具。
- Chrome 156、Firefox 155 各通过 25 项浏览器夹具检查：片段查询、范围恢复、快捷键、网络范围与失败、剪贴板粘贴、打开 URL、插入、textarea 原生撤销、窄视口，以及 CodeMirror 接口调用。
- 固定 1000 页、10000 小节夹具完成首次准备、100 次查询与 20 次重复准备；重复准备没有条目增长、额外协作让步或网络请求。该观察不构成性能保证或内存字节上限。
- 独立审阅发现的修订追平、同页并发核对、缓存失效、后台写锁、状态反馈和首次准备竞态已修复并补测；复核无剩余阻断项。

## 站点协议与验证边界

真实站点读取确认了“世界生成 / 生血晶等七种晶体”和“地形扫描仪 / 你知道吗”的章节元数据。该站 `byteoffset` 实测为 Unicode 码点偏移，适配器转换为 UTF-16 后按源码位置、层级、来源页面和修订核对，不按同名顺序猜测。

浏览器验收使用真实产品模块和隔离数据；中文输入法、CodeMirror 部分使用事件或接口夹具。真实站点快捷键验证在未登录的查看源代码页完成，编辑页保存/预览访问键由隔离探针覆盖。以上不等同于登录编辑器中新安装整包的验收，也不代表远端 CI 或发布成功。

模板动态生成的小节和任意 HTML 标题不保证被本地发现；正文命中所属小节尚未接入。复杂链接离线时无法首次核对。章节 API 不能独立排除模板生成的自定义 DOM ID 冲突；核对缓存仅短期有效，并随已知来源变化失效。
