# 0.3.4 交付验收

日期：2026-09-07。本记录区分本版前期证据、本轮自动化检查与安装整包后的实际操作；不代表远端 CI、Nightly 或部署已验证。

## 交付范围

- 全文命中高亮支持标题／正文独立开关和颜色，正文摘要围绕实际命中选窗；配额检查失败增加诊断，并记录罕见括号键的已知限制。
- 面板按可用视口限宽限高，维护和结果共享滚动区；长状态可展开，支持页面内拖动、键盘移动及复位，沿用站点主题。
- 主操作改为复制纯标题或 Data 代码名。普通页面结果提供打开、复制插入内容、插入；Data/Lua 保留专用打开操作，非 wikitext 不提供插入。
- 增加面板内焦点循环与结果快捷键，保持 IME、原生文本操作、关闭后的焦点恢复及站点外部按键行为。
- 安装与浏览器验收使用独立编辑标签页，不刷新已有编辑页，不在就绪超时后自动重试。
- Vitest 测试集中到按模块分类的 tests 目录，浏览器操作工具保留 scripts；不合并两份标题索引套件，不改测试断言。
- 版本保持 0.3.4；没有新增依赖或改变数据库、事实、索引快照格式。

### 旧版问题与固定数据回归

已安装的 0.3.3 中，搜索框聚焦后第一次按 Tab，焦点仍留在搜索框，但灰机左侧栏展开。这不是只在遍历到最后一个控件时发生的焦点越界。

随后使用当前 SearchPanel 源码及固定的 60 条结果、长状态和维护诊断，运行 `scripts/test-search-panel-layout.playwright.js`：

| 请求视口 | 实际面板宽度（CSS px） | 结果 |
| --- | --- | --- |
| 1200 × 800 | 426.48 | 控件在可见范围内，共享内容滚动 |
| 800 × 420 | 420 | 低高度下搜索、维护、刷新、关闭仍可操作 |
| 360 × 760 | 320.67 | 扣除滚动条后保留两侧安全边距 |
| 3840 × 2160 | 960 | 使用宽度上限，未越界 |

原生 Tab 从搜索框进入模式选择；末端 Tab 回到拖动标题，首端 Shift+Tab 回到状态展开按钮；测试的站点冒泡监听器没有收到这些面板 Tab。真实指针拖动、关闭重开保留位置、Escape 取消第二次拖动、方向键移动和复位均通过。

这些是隔离 UI 验收，维护回调使用固定替身，不执行真实数据库维护。

### 已安装整包

安装器同时核对版本 `0.3.4` 与唯一标识 `CU_WIKI_BUILD_ID:local009-release-20260907`。安装成功时运行态为 bootstrap，未将此结果扩称为完整冷启动性能实验。

运行 `scripts/test-search-panel-actions.playwright.js`，先实际切换搜索模式以准备对应的按需索引，再从当前搜索返回值取首条结果作为期望；不固定线上命中数量。

| 模式 | 本轮查询 | 真实操作结果 |
| --- | --- | --- |
| 标题 | 12号鹿弹 | 主点击／Enter 复制纯标题，复制插入内容保留链接语法，Ctrl+Enter 打开正确目标 |
| 正文 | 12号鹿弹 | 主点击复制纯标题，复制插入内容使用页面标题生成链接 |
| Data | 鹿弹 | 主点击复制代码名，打开来源正确，不支持的插入仅提示 |
| Lua | _meta | 主点击复制完整模块标题，仅保留打开按钮，不支持的插入仅提示 |
| 文件 | morphine | 主点击复制完整文件标题，复制插入内容生成带前导冒号的普通链接 |

复制断言通过真实 Ctrl+V 粘贴到临时文本框完成，不仅检查回调是否触发。复制后面板保持打开。面板内 Tab 不再展开侧栏；离开面板后，站点自身的 Tab 仍可正常开关侧栏。Escape 和 Alt+K 都能恢复原焦点。

在本次独立编辑页中，Shift+Enter 将预期维基链接插入编辑器末尾，原生 Ctrl+Z 后内容与原始文本完全一致。没有保存或提交 Wiki 编辑。
