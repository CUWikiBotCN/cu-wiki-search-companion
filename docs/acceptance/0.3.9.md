# 0.3.9 交付验收

日期：2026-10-03。完成 LOCAL-022～027 六项性能优化；按用户追加要求分阶段提交、提升一个 patch，并在发布前检查后推送。测量数据与复现方式见 [性能记录](../performance/0.3.9.md)。

## 变更

- OpenCC 改用已安装依赖的 t2cn 入口，归一化顺序、转换配置与 analyzer compatibility key 保持不变。
- 状态通知与结果失效分开，六模式各自标脏；合并外部更新与输入防抖，隐藏及 IME 期间暂停查询，重开或组词结束补查。后台刷新保留结果身份和仍存在的按钮/链接焦点。
- 正文摘要按需缓存完整归一化文本，最多 128 页、8 MiB 文本计费；超预算单篇仍返回正确摘要。更新、删除、重建和快照导入清除相应缓存。
- bootstrap 标题按独立序列增量更新，namespace 从内存汇总；标题 handle 增量只保留标题头。正文准备复用同一轮页面筛选结果，取消第二遍 pages 扫描。
- 显式与定时发布共用串行队列，以 handle 和请求身份消费旧任务；文件序列空号不新建页面快照发布。
- 标题 MiniSearch 候选缓存从原始标题计算的 compact 值，保留排序、fuzzy、AND→OR 和线性兜底。

没有新增依赖或 Worker，没有改变 Dexie schema、页面事实、快照 payload、搜索域、请求频率、跨标签写锁或编辑器插入语法。两类缓存只存在于当前索引的内存 state。

## 正确性与发布检查

**45 个测试文件、512 项测试通过**；`npm run build` 包含类型检查并成功构建 0.3.9。修改的 JavaScript 操作脚本经 `node --check`，TypeScript 浏览器夹具经 Vite 生产构建与实际执行。交接、公共相对链接、隐私边界、版本/marker 和 `git diff --check` 检查均通过。

独立 Standards / Spec 审查发现的“部分刷新失败丢通知”和“排队显式发布留下自动重试”均已修复，增加受控异步回归并复审。随后发现的重建安装前失败丢通知、安装后 CSS/诊断失败漏通知也已修复；generation 仅随实际安装推进，三项新增回归和旧刷新丢弃测试均通过。新工具审查发现的采样期间结果稳定性和清理失败路径也已补齐。

## 浏览器实测

专用 Chrome 151.0.7922.173 安装 0.3.9 / `CU_WIKI_BUILD_ID:local022-027-final-039-r3-20261003`，核对精确版本、marker 与 debug ready 后：

- 真实 Wiki 六模式、实际复制/粘贴、打开、面板与站点 Tab、Escape/Alt+K 回焦、Shift+Enter 插入及原生撤销通过。
- 真实 Wiki 繁简结果等价、namespace 筛选、重定向链接独立焦点、IME 期间结果不变/结束补查、隐藏修改查询后重开显示最新结果通过。
- 隔离合成库通过重复通知合并、无关模式和诊断零查询、输入防抖合并、设置框 IME、切模式/销毁取消旧任务、namespace 删除、Data 选择身份、重定向链接保焦及结果移除后的回焦。
- 隔离库通过摘要更新/删除、超预算尾部命中，以及显式发布后等待超过 5 秒的零残余读取/序列化。第二条原生 IndexedDB 连接并发更新与清理时，旧候选被序列/generation 校验拒绝，新更新重试成功，清理后快照表无回写。
- 旧/新生产源码合成查询与输入绘制各三轮配对，结果签名一致；测量了文本计费与 GC 后 heap、快照 Long Task 和整包解析/依赖求值。不同 engine、Node 与浏览器、函数与绘制耗时分别报告。

IME 是 Chrome 中派发 composition 事件的验收，不代表系统输入法设备矩阵。合成 fixture 使用 bootstrap analyzer，最终真实 Wiki 复验确认按需 engine 为 jieba-wasm，两者不混合统计。真实 Wiki 端到端启动未做配对测量；非激活页整包解析/求值不包含 IndexedDB、面板和站点绘制。

未保存 Wiki 编辑、未重置真实镜像、未刷新或关闭原编辑标签。私密 profile、原始日志、合成输出、临时 worktree 和 dist 均不进入 Git。

首次长文 fallback 仍需归一化，浏览器快照采样仍观测到 56 ms Long Task；本版不声称解决首次长文等待或单次同步序列化。8 MiB 是文本计费预算，不能当作真实 heap 增量承诺。
