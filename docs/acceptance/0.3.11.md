# 0.3.11 工程维护验收

日期：2026-10-06。

## 变更范围

- 将同步事件和结果的状态展示映射提取为独立纯函数，集中重复的错误状态转换。
- 明确入口运行态初始化依赖，移除四处运行态非空断言；补充启动失败和提交后本地刷新失败仍通知其他标签的回归覆盖。
- 引入 ESLint、Prettier 和统一 `npm run check`；Vue 模板保留严格空白策略，Playwright CLI 函数表达式脚本只执行 lint，避免格式化破坏调用方式。
- PR 与 push 共用测试、类型、格式、lint 和构建检查；PR 不上传发布资产、不更新 Nightly。
- 本地开发与 CI 统一 Node 24 工具链，精确版本读取 `.nvmrc`，npm 读取 `package.json` 的 `packageManager`，开发文档引用这两处来源。

本次为维护性补丁，未增加用户功能，未改变搜索、同步持久化或存储协议。产品运行依赖保持不变。

## 本地检查

- `npm run check` 通过：lint、格式检查、46 个测试文件中的 547 项测试、类型检查和生产构建。
- 生产构建的 userscript 与更新元数据版本均为 0.3.11；元数据测试核对其与 package 版本一致。
- 更新后的浏览器验收脚本通过语法检查；版本变更仅同步期待值，未执行真实浏览器验收。
- 差异空白检查通过。此前状态映射重构的 10,800 种输入对比保持输出一致；该结果属于重构阶段证据，本次完整检查重新验证最终版本。

## 验证边界

本轮未安装新整包、操作真实 Wiki 或重置真实镜像；历史 UI 与浏览器验收不作为本版本整包实测。

本地检查不代表远端 Actions 或 Nightly 发布成功。本轮推送后不查询 Actions 状态；Vercel 实验部署不在本次验收范围。
