# 0.3.5 交付验收

日期：2026-09-07。此补丁修复 Firefox 中关闭搜索面板后，CodeMirror 光标及链接插入位置回到文首的问题。

## 修复范围

面板关闭时，编辑器模块识别返回目标所属的 CodeMirror 实例，通过实例的 focus 恢复选区与焦点。Alt-K、Esc、关闭按钮、键盘及鼠标插入共用这一条路径。普通控件保留原生聚焦，失效目标仍回退到搜索按钮。

没有新增浏览器判断、选区缓存、依赖或数据库格式。版本同步为 0.3.5。

## 自动化检查

- 新增 9 项集成回归：五种关闭/插入动作，以及 textarea、普通按钮、移除和禁用目标。修复前五种动作分别丢失选区或在文首插入，修复后全部通过。
- 相关编辑器及 UI 测试：3 个文件、45 项通过。
- 全量 `npm test`：38 个文件、381 项通过。
- `npm run build`：TypeScript 与 Vite 生产构建通过。

集成测试模拟已经在 Firefox 观察到的原生焦点选区失配，执行真实 SearchPanel 与插入函数；它不代替浏览器引擎验证。

## 浏览器证据

诊断基线为 Firefox 155.0、CodeMirror 5.58.3 的 contenteditable 模式、已安装脚本 0.3.4。在“世界观”编辑页中，光标原为 line 10/ch 3，Alt-K 打开后仍保留；Alt-K 或 Esc 关闭后变为 line 0/ch 0。键盘和鼠标插入均实测落在文首。

诊断阶段通过临时一次性调用 CodeMirror 的 focus，单光标/跨行选区与五种动作共 10 项检查通过。探针随后移除，所有插入撤销并核对原文。这是修复前的根因验证，不是 0.3.5 整包验收。
