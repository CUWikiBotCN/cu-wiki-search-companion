# 小节链接后台预备验收

日期：2026-11-07。基线：`70bfa64`。本记录对应 0.4.1 的本地实现与验证；提交与推送状态以 Git 记录为准，未进行新版本安装验收。

## 行为

- 移除正常结果上的“链接待核对”和独立核对按钮。复制、打开和插入始终保留入口；未准备好时等待共享请求，完成后执行本次操作一次。
- 结果稳定 300 毫秒后预备前 3 个不同页面；明确单页查询立即预备，选中项等待 150 毫秒并优先于其他后台任务。最大并发为 2，同页同修订与来源序号合并请求，旧查询未开始的任务会被移除。此流程请求章节元数据，不扩大正文自动下载范围。
- 后台失败只输出控制台警告；自动请求冷却 30 秒，用户可立即主动重试。实际动作失败时显示重试和打开所属页面。
- 缓存 5 分钟后进入刷新期，已知来源未变化时最长复用至 15 分钟；收到新的章节证据后不再沿用被否定的旧链接。缓存和冷却记录分别最多 64 页，不持久化。
- 输入、模式、目标、面板焦点或可见性发生变化后取消待执行动作。异步插入还验证 textarea/CodeMirror 内容、选区和变化事件，编辑后再撤销也会取消。普通已就绪操作保持同步执行。
- 本轮只记录控制台信息，不新增诊断页面、导出功能或日志存储。
