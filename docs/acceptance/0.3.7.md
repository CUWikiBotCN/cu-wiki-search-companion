# 0.3.7 交付验收

日期：2026-09-22。本版增加重定向目标展示与 CSS 源码搜索。版本元数据、README、架构与验收脚本同步为 0.3.7；本地工作簿不进入 Git。

## 行为与数据兼容

- 标题模式在命名空间后显示直接重定向目标及章节链接。源页面的复制、打开、插入保持原语义；目标链接独立、可用 Tab 聚焦，长标题自然换行。
- 重定向在标题同步后和增量同步后按 50 标题批量解析，缓存源标题/revision 与直接目标；章节独立编码。全量对账重新核对，失败保留已提交批次，旧响应不能覆盖变化后的源页面。
- CSS 模式搜索站内 `css` / `sanitized-css` 原始源码，区分大小写，保留标点和 Unicode，显示缓存行号与命中高亮。它不是选择器定义解析器，注释也会命中；不搜索外部 CSS、JS 生成样式或跨语言引用。
- CSS 与既有正文下载按范围隔离，共用持久队列和跨标签写锁。独立索引按需读取，只保留 CSS 源码，无新快照、解析依赖或 Worker。
- Dexie schema 保持 v3；page facts 1→2 原地登记，title index 1→2 只使标题快照本地重建，不清页面、队列或远端游标。旧版本标签在后续写锁检查时停止不兼容写入。
